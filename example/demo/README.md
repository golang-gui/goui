# GOUI 控件与功能展厅

在仓库根目录启动：

```bash
go run ./example/demo
```

这是展示公开 API 的应用例程，不是代替专项回归测试的自动化 runner。默认使用
Integrated 窗口、系统主题和内存数据；不开启动画、计时器、开发服务器或外部应用。
左侧选择分类，顶部切换亮暗与主题色，底部显示最近一次操作结果。重启恢复初值；
关闭主窗口退出整个例程，包括已经打开的标签窗口和独立窗口。

标题栏采用 24 DIP Logo、6 DIP 内边距和系统正文字号，常规内容高度约 36 DIP；
不固定最大高度。侧栏仅保留分类导航。底部状态栏最小高度为 28 DIP，内边距
为 6 DIP，长操作结果仍可换行并自然增高，不省略错误信息。

快捷键：Tab / Shift+Tab 转移焦点，空格或 Enter 激活按钮，F5 请求更新声明。
系统操作只在显式点击时启动；这些说明不再常驻侧栏。

顶部语言菜单支持简中、英、日、韩、德、法、俄、阿拉伯八种语言，启动仍为
简中。“使用系统语言”仅在点击时读取当前 Settings 语言并应用一次；工具栏显示
系统与应用标签。未知语言按资源首项英文回退，不把系统区域格式当作界面语言。
Linux 查询进程 locale 环境，中立 C/POSIX 由 GUI 默认英文；不修改系统设置。

语言验收：

- 未编辑时切换八种语言，单行/多行样例、基线/分割示例输入、标签文档、快照
  邀请文字和拖放区域提示均更新；树项目、列表行、表格样例和计时次数也翻译。
  新建标签使用当时的语言；文件名、Widget ID、API 名称不翻译。
- 在文本编辑页输入内容、拖选后切换，标题、分类、提示和编辑右键菜单更新，
  用户文本/选区/撤销历史不变。撤销回原始样例后切换语言，仍可重做，不把
  内容相等当成“尚未编辑”。基线、分割和用户名输入也保留修改后的值。
- 数据页调整列宽、排序并编辑备注后切换，列宽、顺序、选择和已编辑备注保留；
  未编辑备注继续翻译。右键“重置备注”恢复当前语言的默认值，并重新跟随语言。
- 拖文本或卡片到接收区后切换语言，接收说明更新，实际文本和文件路径保持
  原样；空文本也是已接收结果，不能重新显示初始邀请文字。读取快照后切换，
  保留原始 JSON，不把它当成展示提示翻译。
- 打开独立窗口/通用 Popover 后切换，固定展示文本也更新；关闭后再切换不应
  崩溃或保留全局监听。历史操作结果不追溯翻译；阿拉伯文仅验证文字，不承诺
  整窗 RTL 镜像。重启恢复尚未编辑的样例。

## 环境与后端

支持 Windows amd64、macOS arm64 和 Linux X11。Linux Integrated 需要桌面
合成器，不满足时由 GUI 按现有契约回退 Native。窗口位置受系统工作区约束。
macOS 使用 Command 作为编辑快捷键的 Primary，其他平台使用 Ctrl。

可显式选择后端和应用缩放，例如：

```bash
GOUI_PLAT_PAINTER=software GOUI_PLAT_SCALE=1 go run ./example/demo
GOUI_PLAT_PAINTER=opengl GOUI_PLAT_SCALE=2 go run ./example/demo
```

Windows 还可选择 `direct2d`；PowerShell 使用 `$env:GOUI_PLAT_PAINTER='direct2d'`。
应用 2x 覆盖值不是混合 DPI / Retina 验证，建议桌面至少 2400×1700 物理像素。

## Logo 与构建

标题栏、带图标按钮、标签页及动画使用 `doc/logo/goui-mark.svg` 的方形标志，
图形页展示 `doc/logo/goui-logo.svg` 的横版标志。Logo 始终保留 SVG 原色，
不因主题色、亮暗模式或禁用状态染色；单色示范使用独立的普通图标，不使用 Logo。
两份 SVG 原样嵌入 `resource`，
运行不需要源文件，也不依赖当前目录；修改设计后须同步副本，测试检查字节一致。
SVG 保留原设计中的 Go gopher / Renee French / CC BY 4.0 归属说明。

在仓库根目录使用构建工具：

```bash
go run ./cmd/goui build -config example/demo/goui.toml
./example/demo/dist/linux-amd64/goui-demo
```

构建输出位于 `example/demo/dist/<OS>-<ARCH>/`，配置中的方形 SVG 同时用于
平台图标生成。配置路径相对 `goui.toml`，应用 ID 与 `ui.Run` 一致。
可指定 `-target windows/amd64` 或 `-target darwin/arm64`：

- Windows：构建前自动生成 `goui_windows_amd64.syso`，EXE 包含图标和版本资源；
  默认无控制台，不需要另做安装包。
- macOS：`build` 输出裸二进制；要使用应用图标和 bundle 身份，还需执行
  `go run ./cmd/goui package -config example/demo/goui.toml -target darwin/arm64 -format app`。
- Linux：二进制可直接运行；`build` 生成 desktop 与 hicolor 图标资源，但不自动
  安装到系统。`go run ./cmd/goui package -config example/demo/goui.toml -format dir`
  生成包含可执行文件与桌面资源的目录树，部署方式见 `cmd/goui/README.md`。

这些命令不安装图标、修改系统设置或启用沙箱；重复打包须选尚不存在的 `-o` 目录。

## 操作与预期

外观检查：浅色、深色分别观察标题栏 Logo 与文字、窗口控制按钮是否垂直居中；
侧栏末尾没有快捷键说明。将窗口缩至 820×600 DIP，再切换较长文案的语言，
标题和底部结果不应裁掉文字。状态栏短消息紧凑，长消息换行时能自然增高。
放大系统字号并启动后，标题栏跟随增高而不是把标题或原生按钮裁切。

1. 基础控件：点击按钮、复选、三态初值、单选、按钮式 CheckButton 和 Switch；
   单选组最多选一个。关闭“启用下方控件”，交互失效但值保留；再次启用恢复。
   “带图标”按钮的 Logo 保留蓝色窗框和 Gopher 原色细节；切换亮暗、主题色或
   禁用按钮都不将 Logo 染成实心块。警告／错误／成功样例使用普通可着色图标。
   展开两个 DropDown，禁用项目不可选，自定义项目显示图标。Tab / Shift+Tab
   转移焦点，按钮的键盘焦点与点击焦点区别显示；按空格或回车激活聚焦的按钮。
   右侧滚动条应完整呈胶囊形，滚动页在视口外保留 8 DIP 对称留白，避免
   滑块紧贴窗口边缘。Linux 自绘 Integrated 普通状态外侧仍保留窗口管理的缩放区域；
   最大化/全屏及其他平台不额外添加这段避让。缩窄窗口、最大化再恢复后，
   滚动条仍应完整可见，左右两侧都可点击、拖动，不应被窗口边缘裁掉。
   Modern 展示：内容 section 使用 `modern.Card`，侧栏外壳使用 `modern.Sidebar`，
   未选中的分类按钮使用 `modern.Flat`，当前页使用私有中性选中样式。主要操作按钮
   使用 Primary 主题色实底，子 Label 显式使用 PrimaryContent 的对比前景；禁用后
   底色和文字均弱化，切换亮暗／主题色时仍可读。扁平按钮平时无底色
   和普通边框，悬停/按下恢复普通按钮的中性背景和 1 DIP 描边，文字位置不跳动；
   点击显示反馈，禁用扁平按钮保持透明无框且不会触发。
   Tab 聚焦仍有 2 DIP 边框。语义样式卡片中的警告/错误/成功文字与图标分别
   为琥珀/红/绿，切换亮暗保持可读，切换主题色不改变这三种颜色。
   新展示文本也跟随八语言切换；HBox/VBox 自身不绘制 Card/Sidebar，表面由
   本例原有的 surface 控件绘制，不隐式给子控件提供样式或 Padding。
2. 文本编辑：单行输入后按 Enter，反馈显示提交内容。在多行编辑区输入中文、
   Emoji，拖选、右键、复制/粘贴、撤销/重做。切换换行/只读，选区和行数有反馈。
   分别聚焦单行输入框和多行编辑区，Ctrl/Cmd+A 后按 Backspace 清空：显示单行／
   两行占位提示，输入后消失，再次清空后恢复。提示不改变空正文的行数和选区。
   保持空内容切换八种语言、亮暗和主题色，提示随之更新，不重新填入示例文本。
   多行编辑区清空后可撤销恢复正文、重做恢复提示；空编辑区切换只读仍显示提示，
   键入不能修改内容。关闭只读后继续输入，切换分类再返回，正文和历史继续保留。
   切换分类再回来，模型文本和撤销历史保留；视图自己的滚动/焦点不承诺保留。
3. 布局与滚动：拖动独立水平 ScrollBar，数值变化。调整窗口宽度，HWrap 折行；
   VWrap 在固定高度内换列。观察标签与输入框基线；拖动 HSplit / VSplit，
   两侧保持可滚动，改变子内容不会重新强制恢复初始分割尺寸。快速拖过其他
   控件时缩放箭头应保持，释放后再恢复当前命中控件的光标。
4. 数据浏览：展开 TreeView、Ctrl/Cmd 多选、右键查看节点 ID 或复制节点名；
   点击 TableView 列头排序、拖列界调整宽度，编辑备注。缩放列后排序、F5 重建、
   切换亮暗和分类返回均保留新列宽。备注按行 ID 跟随排序；
   单元格填满，编辑器普通状态无独立边框、焦点状态为直角主题色边框。
   滚动下方 1000 行 ListView，点击行显示对应序号。
5. 多标签工作区：新建、选中、右键和关闭标签；关闭在标签所在窗口确认。
   标签图标同样使用原色 Logo，选中／未选中和主题色切换不改变品牌配色。
   拖动标签排序，窗口变窄时一起缩小至阈值后滚动。打开目标窗口，将其移到
   主窗口外的可见位置再拖入标签；输入内容跟随原页面，不是拷贝第二个编辑器。
   标签拖到桌面或外部应用松开创建新窗口；本地标签不向外部应用提供可接收的
   文本/文件数据，不应留下接收提示。新窗口显示前定位，并避让目标原生控制
   按钮；非工作区边缘释放时鼠标仍在新窗口标签的原抓取位置。
   新窗口标签栏空白可以拖动窗口，标签本体仍排序/移交，不被误判为标题区域。
   源只剩一个标签时不再创建新窗口，但仍可移交到其他标签窗口。Esc 取消拖放。
   关闭额外窗口丢弃其文档；不自动把页面迁回主窗口。
6. 菜单与覆盖层：普通/长菜单、通用 Popover 都使用窗口外 Popup。窗口移到
   桌面边缘后重开，观察定位退避。中文短菜单主体默认至少 160 DIP（含内部留白、
   不含阴影），长文字仍自然撑宽；工作区不足时允许收缩。切换亮暗和语言后重开，
   行背景和点击范围应随宽度铺开，短菜单无多余横向滚动条。长菜单竖向滚动时，
   菜单项与滚动条保留间距；此默认宽度不应用于 DropDown 或通用 Popover。
   浮动面板外可继续操作背景；遮罩覆盖之后
   该内容页内的背景鼠标/滚轮不能穿透；分类导航和主题工具栏在遮罩区域之外。
   分别在浅色、深色打开查找面板和确认 Dialog：面板、Dialog、Toast 均使用
   `modern.Card` 不透明圆角背景与柔和边框，不能透出下方文字；只有遮罩半透明。
   多标签工作区的关闭确认框也遵循同一外观；切换亮暗时背景应同步更新。
   确认后显示 Toast，3 秒消失；离开分类取消 Toast。
   这个 Dialog 是指针遮罩示范，不提供键盘模态、焦点圈定或后台快捷键屏蔽。
7. 图形与动画：切换主题色，单色 SVG/自定义图标重绘，原色 SVG 和固定 Image
   保留颜色；标题栏的方形 logo 和本页横版 logo 保持蓝色、灰色等原设计配色，
   不拉伸、不遮挡文字，透明外缘不出现底色方块。观察透明叠加、变换与裁剪；
   点击 RenderWidget 显示离屏结果。
   动画区域同样使用原色方形 logo，不应显示为主题色实心方块；启动尺寸动画后
   在 32～80 DIP 之间变化，可以重定向、停止或跳至终值；进度与数值同步。忙等待的长条
   向前循环，圆形旋转。默认停止，离开该分类停止演示动画和忙等待。
8. 系统与拖放：复制/读取剪贴板、选择文件/目录、保存对话框只展示路径。
   打开网站会启动默认浏览器，打开选中项会调用系统默认应用。
   启动计数后每秒更新，停止或离开分类后不再计时。拖卡片到接收区、拖文本到
   其他编辑器、把系统文件拖入接收区；反馈显示数据。选择真实文件后才能拖出
   文件。预览通过公开 RenderWidget 生成；应用内卡片不接受外部伪造。
9. 窗口与检查：创建 Native / Integrated / 透明 None 窗口，尝试拖标题和相对
   主窗口定位。原“透明 None 窗口”示例只提供标题拖动和关闭，不宣称有完整自绘缩放光标。
   Native 请拖系统标题栏；Integrated / None 拖内容中的 HeaderBar。
   打开或关闭 Integrated / 透明 None 辅助窗口都不应改变主窗口边缘背景；
   浅色、深色分别检查一次。透明 None 的面板外侧应透出桌面，主窗口边缘仍
   保持自己的不透明底色；内部面板使用 `modern.Card`，背景不透明。
   可同时打开两个透明窗口，再逐个关闭检查。
   新增“不占任务栏窗口”使用 Native + SkipTaskbar：Windows/X11 不增加独立任务栏
   项（X11 窗口管理器可忽略请求）；Windows Alt+Tab 也不包含此窗，macOS 应用 Dock
   图标保持不变。该窗口仍可激活、输入、移动和缩放，不等于 Popup 或置顶窗口。
   新增“BorderBox 自绘窗口”使用 None + Transparent，以 BorderBox 为实际根；
   拖动 HeaderBar 移动，拖四边/四角缩放，边缘显示相应方向光标，留白为 6 DIP。
   此例显式选择 `modern.Card` 圆角和描边，BorderBox 默认无外观的规则不变；
   四角透出桌面，输入框与滚动内容不能盖住边框。缩小窗口后可滚动到“关闭此窗”，
   HeaderBar 不随内容滚动。两个新例初始请求 500×380 DIP，最小为 280×220 DIP，
   不用长说明的自然宽度限制缩小。依次关闭或打开两个新例都不能改变主窗口背景。
   在两个新窗口输入文字，切换浅色/深色及中/英/德语言：窗口标题、固定说明、
   按钮更新，用户输入保持不变；关闭辅助窗后继续切换语言不能访问已销毁控件。
   请求最大化/普通状态，读取实际位置、工作区和原生状态。
   读取 Snapshot 展示角色、状态、布局边界、ID 与子树；按 ID 查找反馈真实类型。
   快照只用于检查，不绕过输入分发执行动作。

透明与背景色是两件事。透明 None 示例通过 `Window.SetStyleName` 选择专用的
`demo-transparent-window` 背景；其他窗口继续使用默认 `window`，样式表和
主题仍由应用统一提供。切换主题不会丢失各窗口自己的样式选择，不修改共享
`window` 规则。Linux Integrated 本身需要 alpha surface，但不意味着用户希望
清空背景；透明选项仍是不可切换的窗口创建配置。
透明窗口的空白区域也不代表鼠标穿透；本例不实现输入区域裁剪。

## 副作用与边界

- 只在点击“复制”或文本编辑命令时写剪贴板；可覆盖原内容。
- 文件对话框不自动读取文件，保存对话框不创建文件。拖入仅接收路径。
- 打开网站/路径和跨应用拖出需人工主动执行；目标应用可能按自己的规则读取、
  复制或移动文件，框架例程不能撤回外部应用产生的副作用。
- 对话框 UI API 的空结果同时可能表示取消或不可用，不伪称成功，也不细分其
  未提供的错误原因；OpenURL / OpenPath 的公开错误直接显示。
- 不展示尚未提供的子菜单、Tooltip、系统通知/托盘或完整键盘模态等功能。

例程文件按场景拆分；数据、文本模型和图标资源在 `newDemo` 创建，Build 只声明。
`surface.go` / `scrollbar.go` 示范标准 Bin / WidgetView / Scrollable 扩展，无核心改动。
不依赖桌面的例程逻辑测试：`go test ./example/demo`。
开发中发现的框架问题与易用性限制见 [DemoFrameworkNotes](../../doc/DemoFrameworkNotes.md)。
