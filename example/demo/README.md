# GOUI 控件与功能展厅

在仓库根目录启动：

```bash
go run ./example/demo
```

这是展示公开 API 的应用例程，不是代替专项回归测试的自动化 runner。默认使用
Integrated 窗口、系统主题和内存数据；不开启动画、计时器、开发服务器或外部应用。
左侧选择分类，顶部切换亮暗与主题色，底部显示最近一次操作结果。重启恢复初值；
关闭主窗口退出整个例程，包括已经打开的标签窗口和独立窗口。

顶部语言菜单支持简中、英、日、韩、德、法、俄、阿拉伯八种语言，启动仍为
简中。“使用系统语言”仅在点击时读取当前 Settings 语言并应用一次；工具栏显示
系统与应用标签。未知语言按资源首项英文回退，不把系统区域格式当作界面语言。
Linux 查询进程 locale 环境，中立 C/POSIX 由 GUI 默认英文；不修改系统设置。

语言验收：在文本编辑页输入内容、拖选后切换八种语言，标题、分类、提示和
编辑右键菜单更新，文本/选区/撤销历史不变；在数据页调整列宽、排序并编辑
备注后切换，列宽、顺序和内容保留。打开独立窗口/通用 Popover 后切换，固定
展示文本也更新；关闭后再切换不应崩溃或保留全局监听。用户数据、文档、路径
和历史操作结果不会被重新翻译；阿拉伯文仅验证文字，不承诺整窗 RTL 镜像。

## 环境与后端

支持 Windows amd64、macOS arm64 和 Linux X11。Linux Integrated 需要桌面
合成器，不满足时由 GUI 按现有契约回退 Native。窗口位置受系统工作区约束。
macOS 使用 Command 作为编辑快捷键的 Primary，其他平台使用 Ctrl。

可显式选择后端和应用缩放，例如：

```bash
GOUI_PLAT_PAINTER=software GOUI_PLAT_SCALE=1 go run ./example/demo
GOUI_PLAT_PAINTER=opengl GOUI_PLAT_SCALE=2 go run ./example/demo
```

Windows 还可选择 `direct2d`；PowerShell 使用 `$env:GOUI_PLAT_PAINTER='direct2d'`。
应用 2x 覆盖值不是混合 DPI / Retina 验证，建议桌面至少 2400×1700 物理像素。

## 操作与预期

1. 基础控件：点击按钮、复选、三态初值、单选、按钮式 CheckButton 和 Switch；
   单选组最多选一个。关闭“启用下方控件”，交互失效但值保留；再次启用恢复。
   展开两个 DropDown，禁用项目不可选，自定义项目显示图标。Tab / Shift+Tab
   转移焦点，按钮的键盘焦点与点击焦点区别显示；按空格或回车激活聚焦的按钮。
   右侧滚动条应完整呈胶囊形，滚动页在视口外保留 8 DIP 对称留白，避免
   滑块紧贴窗口边缘。Linux 自绘 Integrated 普通状态外侧仍保留窗口管理的缩放区域；
   最大化/全屏及其他平台不额外添加这段避让。缩窄窗口、最大化再恢复后，
   滚动条仍应完整可见，左右两侧都可点击、拖动，不应被窗口边缘裁掉。
2. 文本编辑：单行输入后按 Enter，反馈显示提交内容。在多行编辑区输入中文、
   Emoji，拖选、右键、复制/粘贴、撤销/重做。切换换行/只读，选区和行数有反馈。
   切换分类再回来，模型文本和撤销历史保留；视图自己的滚动/焦点不承诺保留。
3. 布局与滚动：拖动独立水平 ScrollBar，数值变化。调整窗口宽度，HWrap 折行；
   VWrap 在固定高度内换列。观察标签与输入框基线；拖动 HSplit / VSplit，
   两侧保持可滚动，改变子内容不会重新强制恢复初始分割尺寸。快速拖过其他
   控件时缩放箭头应保持，释放后再恢复当前命中控件的光标。
4. 数据浏览：展开 TreeView、Ctrl/Cmd 多选、右键查看节点 ID 或复制节点名；
   点击 TableView 列头排序、拖列界调整宽度，编辑备注。缩放列后排序、F5 重建、
   切换亮暗和分类返回均保留新列宽。备注按行 ID 跟随排序；
   单元格填满，编辑器普通状态无独立边框、焦点状态为直角主题色边框。
   滚动下方 1000 行 ListView，点击行显示对应序号。
5. 多标签工作区：新建、选中、右键和关闭标签；关闭在标签所在窗口确认。
   拖动标签排序，窗口变窄时一起缩小至阈值后滚动。打开目标窗口，将其移到
   主窗口外的可见位置再拖入标签；输入内容跟随原页面，不是拷贝第二个编辑器。
   标签拖到桌面或外部应用松开创建新窗口；本地标签不向外部应用提供可接收的
   文本/文件数据，不应留下接收提示。新窗口显示前定位，并避让目标原生控制
   按钮；非工作区边缘释放时鼠标仍在新窗口标签的原抓取位置。
   新窗口标签栏空白可以拖动窗口，标签本体仍排序/移交，不被误判为标题区域。
   源只剩一个标签时不再创建新窗口，但仍可移交到其他标签窗口。Esc 取消拖放。
   关闭额外窗口丢弃其文档；不自动把页面迁回主窗口。
6. 菜单与覆盖层：普通/长菜单、通用 Popover 都使用窗口外 Popup。窗口移到
   桌面边缘后重开，观察定位退避。浮动面板外可继续操作背景；遮罩覆盖之后
   该内容页内的背景鼠标/滚轮不能穿透；分类导航和主题工具栏在遮罩区域之外。
   确认后显示 Toast，3 秒消失；离开分类取消 Toast。
   这个 Dialog 是指针遮罩示范，不提供键盘模态、焦点圈定或后台快捷键屏蔽。
7. 图形与动画：切换主题色，单色 SVG/自定义图标重绘，原色 SVG 和固定 Image
   保留颜色。观察透明叠加、变换与裁剪；点击 RenderWidget 显示离屏结果。
   启动尺寸动画后可以重定向、停止或跳至终值；进度与数值同步。忙等待的长条
   向前循环，圆形旋转。默认停止，离开该分类停止演示动画和忙等待。
8. 系统与拖放：复制/读取剪贴板、选择文件/目录、保存对话框只展示路径。
   打开网站会启动默认浏览器，打开选中项会调用系统默认应用。
   启动计数后每秒更新，停止或离开分类后不再计时。拖卡片到接收区、拖文本到
   其他编辑器、把系统文件拖入接收区；反馈显示数据。选择真实文件后才能拖出
   文件。预览通过公开 RenderWidget 生成；应用内卡片不接受外部伪造。
9. 窗口与检查：创建 Native / Integrated / 透明 None 窗口，尝试拖标题和相对
   主窗口定位。None 的示例只提供标题拖动和关闭，不宣称有完整自绘缩放光标。
   Native 请拖系统标题栏；Integrated / None 拖内容中的 HeaderBar。
   打开或关闭 Integrated / 透明 None 辅助窗口都不应改变主窗口边缘背景；
   浅色、深色分别检查一次。透明 None 的面板外侧应透出桌面，主窗口边缘仍
   保持自己的不透明底色；可同时打开两个透明窗口，再逐个关闭检查。
   请求最大化/普通状态，读取实际位置、工作区和原生状态。
   读取 Snapshot 展示角色、状态、布局边界、ID 与子树；按 ID 查找反馈真实类型。
   快照只用于检查，不绕过输入分发执行动作。

透明与背景色是两件事。透明 None 示例通过 `Window.SetStyleName` 选择专用的
`demo-transparent-window` 背景；其他窗口继续使用默认 `window`，样式表和
主题仍由应用统一提供。切换主题不会丢失各窗口自己的样式选择，不修改共享
`window` 规则。Linux Integrated 本身需要 alpha surface，但不意味着用户希望
清空背景；透明选项仍是不可切换的窗口创建配置。
透明窗口的空白区域也不代表鼠标穿透；本例不实现输入区域裁剪。

## 副作用与边界

- 只在点击“复制”或文本编辑命令时写剪贴板；可覆盖原内容。
- 文件对话框不自动读取文件，保存对话框不创建文件。拖入仅接收路径。
- 打开网站/路径和跨应用拖出需人工主动执行；目标应用可能按自己的规则读取、
  复制或移动文件，框架例程不能撤回外部应用产生的副作用。
- 对话框 UI API 的空结果同时可能表示取消或不可用，不伪称成功，也不细分其
  未提供的错误原因；OpenURL / OpenPath 的公开错误直接显示。
- 不展示尚未提供的子菜单、Tooltip、系统通知/托盘或完整键盘模态等功能。

例程文件按场景拆分；数据、文本模型和图标资源在 `newDemo` 创建，Build 只声明。
`surface.go` / `scrollbar.go` 示范标准 Bin / WidgetView / Scrollable 扩展，无核心改动。
不依赖桌面的例程逻辑测试：`go test ./example/demo`。
开发中发现的框架问题与易用性限制见 [DemoFrameworkNotes](../../doc/DemoFrameworkNotes.md)。
